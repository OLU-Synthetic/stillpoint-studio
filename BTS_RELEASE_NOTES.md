# BTS Release Notes

## Watermark

Use a tiny corner mark only:

Stillpoint Studio

Do not use a giant diagonal watermark. It makes the work look defensive and cheap.

## Crop/export

Instagram carousel:
- 4:5 vertical works best: 1080 × 1350
- Square is acceptable: 1080 × 1080
- Keep the mark small: 28–42 px tall at 1080 width

Website:
- Export long edge around 1800–2400 px
- Use JPG quality around 80–88
- Avoid uploading massive 8–15 MB images to GitHub Pages
